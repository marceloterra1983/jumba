## 4. Estado das verificações (2026-11-04)

**`precificacao`: APROVADO COM RESSALVAS.** Nenhum valor numérico está errado.

- **O que foi conferido:** os 82 casos foram recalculados num script próprio, em double com `math.erfc`, sem usar nada de `geradores/`. Foram 1.126 comparações de campo, e nenhuma ficou fora da tolerância gravada.
